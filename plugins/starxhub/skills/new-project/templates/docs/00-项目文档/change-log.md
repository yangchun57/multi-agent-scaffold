# 需求变更记录

> 由 requirement-analyst / pm Agent 维护。每次需求变更在此记录。

## 变更状态机

```
提出 → 分析中 → 已规划 → 实施中 → 已完成 → 已归档
```

## 变更记录表

| 变更ID | 日期 | 类型 | 内容摘要 | 影响范围 | 状态 |
|--------|------|------|----------|----------|------|

- **提出**：{日期}
- **影响分析**：
