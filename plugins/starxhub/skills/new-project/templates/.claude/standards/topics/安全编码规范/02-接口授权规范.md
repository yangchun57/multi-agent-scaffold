# 安全编码规范 · 接口授权规范

> 对应问题：C-1（管理接口无角色鉴权）

## 强制规则

### 1. Controller 必须显式标注授权

**所有 Controller 类或方法必须标注 `[Authorize]` 或 `[AllowAnonymous]`，禁止遗漏。**

```csharp
// ✅ 正确：类级别标注
[Authorize(Roles = "Admin")]
[ApiController]
[Route("api/[controller]")]
public class AdminController : ControllerBase
{
    [HttpDelete("{id}")]
    public async Task<ApiResult<bool>> Delete(long id)
    {
        // 仅 Admin 角色可访问
    }
}

// ✅ 正确：方法级别标注
[ApiController]
[Route("api/[controller]")]
public class RegistrationController : ControllerBase
{
    [AllowAnonymous]  // 公开接口显式标注
    [HttpPost]
    public async Task<ApiResult<long>> Register([FromBody] RegisterRequest request)
    {
        // 无需登录
    }

    [Authorize]  // 需要登录
    [HttpGet("list")]
    public async Task<ApiResult<PageResult<Registration>>> List([FromQuery] QueryRequest query)
    {
        // 需要登录
    }
}

// ❌ 错误：未标注授权
[ApiController]
[Route("api/[controller]")]
public class AdminController : ControllerBase  // 缺少 [Authorize]
{
    [HttpDelete("{id}")]
    public async Task<ApiResult<bool>> Delete(long id)
    {
        // 任何登录用户都能调用！
    }
}
```

### 2. 管理接口必须使用角色鉴权

```csharp
// ✅ 正确：角色鉴权
[Authorize(Roles = "Admin")]
public class AdminController : ControllerBase { }

// ✅ 正确：策略鉴权（更灵活）
[Authorize(Policy = "RequireAdminRole")]
public class AdminController : ControllerBase { }

// ❌ 错误：仅 [Authorize] 无角色限制
[Authorize]  // 任何登录用户都能访问
public class AdminController : ControllerBase { }
```

### 3. 公开接口必须配置速率限制

```csharp
// Program.cs
builder.Services.AddRateLimiter(options =>
{
    options.AddFixedWindowLimiter("RegistrationLimiter", opt =>
    {
        opt.PermitLimit = 5;  // 每窗口最多 5 次
        opt.Window = TimeSpan.FromMinutes(1);
        opt.QueueLimit = 0;
    });
});

// Controller
[AllowAnonymous]
[HttpPost]
[EnableRateLimiting("RegistrationLimiter")]
public async Task<ApiResult<long>> Register([FromBody] RegisterRequest request)
{
    // 每分钟最多 5 次注册
}
```

## 检查方法

```bash
# 查找未标注授权的 Controller
grep -r "public class.*Controller" --include="*.cs" | while read line; do
  file=$(echo "$line" | cut -d: -f1)
  if ! grep -q "\[Authorize" "$file"; then
    echo "⚠️ 缺少授权: $file"
  fi
done
```
