# 前端工程健壮性规范 · 文件上传与移动端规范

> 对应问题：H-6（前端文件上传删除手动 Content-Type）、M-8（手机号输入缺少数字键盘）

## 文件上传规范

### 1. 禁止手动设置 Content-Type

```typescript
// ❌ 错误：手动设置 multipart/form-data
async function uploadFile(file: File) {
  const formData = new FormData()
  formData.append('file', file)
  
  const res = await axios.post('/api/upload', formData, {
    headers: {
      'Content-Type': 'multipart/form-data'  // 错误！
    }
  })
  return res.data
}

// ✅ 正确：让浏览器自动设置（包含 boundary）
async function uploadFile(file: File) {
  const formData = new FormData()
  formData.append('file', file)
  
  // 不设置 Content-Type，浏览器会自动添加正确的 boundary
  const res = await axios.post('/api/upload', formData)
  return res.data
}
```

### 2. 前端文件校验

```typescript
// ✅ 完整示例：文件上传前校验
const MAX_FILE_SIZE = 5 * 1024 * 1024  // 5 MB
const ALLOWED_TYPES = ['image/jpeg', 'image/png', 'application/pdf']

function validateFile(file: File): string | null {
  // 1. 校验大小
  if (file.size > MAX_FILE_SIZE) {
    return `文件大小不能超过 5MB`
  }
  
  // 2. 校验类型
  if (!ALLOWED_TYPES.includes(file.type)) {
    return `不支持的文件类型: ${file.type}`
  }
  
  return null
}

// 使用
async function handleFileChange(file: File) {
  const error = validateFile(file)
  if (error) {
    ElMessage.error(error)
    return
  }
  
  uploading.value = true
  try {
    const res = await uploadFile(file)
    if (res.code === 200) {
      ElMessage.success('上传成功')
      fileUrl.value = res.data.url
    } else {
      ElMessage.error(res.message || '上传失败')
    }
  } catch (error) {
    handleError(error, 'uploadFile')
  } finally {
    uploading.value = false
  }
}
```

## 移动端规范

### 1. 手机号输入框使用数字键盘

```vue
<!-- ❌ 错误：使用默认文本键盘 -->
<input type="text" v-model="phone" placeholder="请输入手机号" />

<!-- ✅ 正确：H5 页面使用 inputmode="numeric" -->
<input 
  type="text" 
  inputmode="numeric" 
  pattern="[0-9]*"
  v-model="phone" 
  placeholder="请输入手机号" 
/>

<!-- ✅ 正确：小程序使用 type="number" -->
<input type="number" v-model="phone" placeholder="请输入手机号" />
```

### 2. 表单验证规则

```typescript
// ✅ 手机号验证（支持带空格/横杠的输入）
const phoneRules = [
  { required: true, message: '请输入手机号', trigger: 'blur' },
  {
    validator: (rule: any, value: string, callback: any) => {
      if (!value) {
        callback(new Error('请输入手机号'))
        return
      }
      
      // 移除空格和横杠
      const cleanPhone = value.replace(/[\s-]/g, '')
      
      // 验证格式
      if (!/^1[3-9]\d{9}$/.test(cleanPhone)) {
        callback(new Error('手机号格式不正确'))
        return
      }
      
      callback()
    },
    trigger: 'blur'
  }
]
```

### 3. 性别字段使用枚举

```typescript
// ✅ 正确：使用枚举类型
export enum Gender {
  Male = 1,
  Female = 2,
  Unknown = 0
}

export const GenderLabel: Record<number, string> = {
  [Gender.Male]: '男',
  [Gender.Female]: '女',
  [Gender.Unknown]: '未知'
}

// 表单中使用
const form = reactive({
  name: '',
  phone: '',
  gender: Gender.Unknown as Gender  // 初始化为未知，而非默认值
})

// 验证规则
const genderRules = [
  { 
    required: true, 
    validator: (rule: any, value: Gender, callback: any) => {
      if (value === Gender.Unknown) {
        callback(new Error('请选择性别'))
        return
      }
      callback()
    },
    trigger: 'change'
  }
]
```
