# 前端开发规范 · 五、样式规范

> 拆分自《前端开发规范》第 5 节。需要全量上下文时读原文件。


### 全局样式重置（强制）

浏览器 user agent 默认会给 `body` 添加 `margin: 8px`，必须在全局样式中显式重置，否则页面四周出现白边。

在全局样式文件（如 `src/styles/variables.scss` 或 `src/styles/global.scss`，须在 `main.ts` 中 import）中加入：

```css
body {
  margin: 0;
}
```

> 此规则适用于所有新项目。Element Plus 等 UI 库不会替开发者重置 body margin。

### 5.1 样式作用域

所有组件样式必须使用 `scoped`：

```vue
<style scoped>
/* 组件私有样式 */
</style>
```

### 5.2 类名命名

使用 kebab-case 命名类名：

```css
/* 推荐 */
.card-header {}
.search-form {}
.pagination {}

/* 不推荐 */
.cardHeader {}
.searchForm {}
```

### 5.3 统一尺寸

| 元素 | 宽度 |
|------|------|
| 选择器 | 160px |
| 日期选择器 | 150px |
| 状态选择器 | 120px |
| 输入框 | 180px |

```vue
<el-select v-model="query.status" style="width: 120px">
<el-date-picker v-model="query.period" style="width: 150px">
<el-input v-model="query.keyword" style="width: 180px">
```

### 5.4 常用样式类

```css
/* 卡片标题 */
.card-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

/* 搜索表单 */
.search-form {
  margin-bottom: 16px;
}

/* 分页 */
.pagination {
  margin-top: 16px;
  justify-content: flex-end;
}

/* 汇总栏 */
.summary-bar {
  margin-bottom: 16px;
  display: flex;
  gap: 12px;
}
```
