# 后端开发规范 · 十一、依赖注入规范

> 拆分自《后端开发规范》第 11 节。需要全量上下文时读原文件。


### 11.1 服务注册

```csharp
// Program.cs

// 注册 SqlSugar
builder.Services.AddScoped<ISqlSugarClient>(sp => { /* ... */ });

// 注册服务（使用 Scrutor 自动扫描）
builder.Services.Scan(scan => scan
    .FromAssemblyOf<IDepartmentService>()
    .AddClasses(classes => classes.Where(type => type.Name.EndsWith("Service")))
    .AsImplementedInterfaces()
    .WithScopedLifetime());

// 手动注册
builder.Services.AddScoped<IDepartmentService, DepartmentService>();
builder.Services.AddScoped<IMeterService, MeterService>();
builder.Services.AddScoped<IReadingService, ReadingService>();
builder.Services.AddScoped<IBillingService, BillingService>();
```

### 11.2 服务生命周期

| 生命周期 | 使用场景 | 示例 |
|---------|---------|------|
| Singleton | 无状态服务、全局配置 | `IConfiguration`, `ILogger` |
| Scoped | 业务服务（每个请求一个实例） | `IDepartmentService`, `ISqlSugarClient` |
| Transient | 轻量级、无状态服务 | 工具类服务 |
