# 前端开发规范 · 十一、代码审查清单

> 拆分自《前端开发规范》第 11 节。需要全量上下文时读原文件。


### 11.1 组件审查

- [ ] 组件命名是否符合规范
- [ ] Props 和 Emits 是否使用 TypeScript 类型
- [ ] 样式是否使用 scoped
- [ ] 是否有未使用的导入
- [ ] 是否正确处理 loading 状态

### 11.2 类型审查

- [ ] 类型定义是否完整
- [ ] 是否避免使用 any
- [ ] 枚举是否同时定义 Label 和 Type
- [ ] 查询参数是否继承 PageQuery

### 11.3 API 审查

- [ ] 接口命名是否规范
- [ ] 返回类型是否正确
- [ ] 是否处理错误情况
- [ ] 是否使用 try-finally 处理 loading

### 11.4 样式审查

- [ ] 下拉框宽度是否符合规范
- [ ] 类名是否使用 kebab-case
- [ ] 是否避免硬编码颜色值
