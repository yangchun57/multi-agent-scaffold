### 1.1 目录结构

```
src/
├── api/                 # API 接口定义
│   ├── request.ts       # Axios 实例配置
│   ├── family-base.ts   # 按模块划分 API
│   └── family-meter.ts
├── components/          # 公共组件
│   ├── CampusSelector.vue
│   ├── CommunitySelector.vue
│   └── ...
├── layouts/             # 布局组件
│   └── DefaultLayout.vue
├── mock/                # Mock 数据
│   ├── _database.ts     # 模拟数据库
│   ├── _helpers.ts      # 工具函数
│   └── modules/         # 按模块划分
├── router/              # 路由配置
│   └── index.ts
├── stores/              # Pinia 状态管理
│   └── user.ts
├── styles/              # 全局样式
│   └── variables.scss
├── types/               # TypeScript 类型定义
│   ├── api.d.ts         # 通用 API 类型
│   ├── family.d.ts      # 按模块划分类型
│   └── enums.ts         # 枚举定义
├── utils/               # 工具函数
│   └── format.ts
└── views/               # 页面组件
    ├── family/          # 按业务模块划分
    │   ├── base/        # 子模块
    │   └── ...
    └── ...
```

### 1.2 文件命名

| 类型 | 命名规范 | 示例 |
|------|---------|------|
| 页面组件 | PascalCase + 功能描述 | `MeterList.vue`, `FamilyBillingList.vue` |
| 公共组件 | PascalCase + 功能Selector | `CampusSelector.vue`, `DeptSelector.vue` |
| 类型文件 | kebab-case.d.ts | `family.d.ts`, `api.d.ts` |
| API 文件 | kebab-case.ts | `family-base.ts`, `family-meter.ts` |
| Mock 文件 | kebab-case.mock.ts | `family-base.mock.ts` |
| 工具函数 | camelCase.ts | `format.ts` |
