# 安全编码规范 · 多租户数据隔离规范

> 对应问题：C-3（多租户数据无隔离）

## 强制规则

### 1. 所有查询必须带租户过滤

```csharp
// ❌ 错误：未过滤租户
public async Task<List<Registration>> GetAll()
{
    return await _db.Queryable<Registration>().ToListAsync();
    // 会返回所有租户的数据！
}

// ✅ 正确：显式过滤租户
public async Task<List<Registration>> GetAll(long tenantId)
{
    return await _db.Queryable<Registration>()
        .Where(r => r.TenantId == tenantId)
        .ToListAsync();
}

// ✅ 更好：使用全局过滤器（SqlSugar）
public class Registration : ITenantEntity
{
    public long Id { get; set; }
    public long TenantId { get; set; }  // 必须字段
    // ...
}

// 配置全局过滤器
_db.QueryFilter.AddTableFilter<ITenantEntity>(it => 
    it.TenantId == _currentTenantId);
```

### 2. 租户 ID 必须从认证信息获取

```csharp
// ❌ 错误：从请求参数获取租户 ID
[HttpGet]
public async Task<ApiResult<List<Registration>>> List([FromQuery] long tenantId)
{
    var data = await _service.GetAll(tenantId);  // 用户可伪造 tenantId！
    return ApiResult.Ok(data);
}

// ✅ 正确：从 JWT Claim 获取租户 ID
[HttpGet]
public async Task<ApiResult<List<Registration>>> List()
{
    var tenantId = GetCurrentTenantId();  // 从 Claims 获取
    var data = await _service.GetAll(tenantId);
    return ApiResult.Ok(data);
}

private long GetCurrentTenantId()
{
    var claim = User.FindFirst("TenantId");
    if (claim == null)
    {
        throw new BusinessException("用户未绑定租户", 403);
    }
    return long.Parse(claim.Value);
}
```

### 3. 实体必须实现租户接口

```csharp
// 定义租户接口
public interface ITenantEntity
{
    long TenantId { get; set; }
}

// 所有业务实体必须实现
public class Registration : ITenantEntity
{
    public long Id { get; set; }
    public long TenantId { get; set; }  // 必须字段
    public string Name { get; set; }
    // ...
}

public class CompanyInfo : ITenantEntity
{
    public long Id { get; set; }
    public long TenantId { get; set; }  // 必须字段
    public string CompanyName { get; set; }
    // ...
}
```

### 4. 数据库迁移必须添加租户字段

```sql
-- ✅ 正确：所有业务表必须有 TenantId
CREATE TABLE Registration (
    Id BIGINT PRIMARY KEY,
    TenantId BIGINT NOT NULL,  -- 必须字段
    Name NVARCHAR(100) NOT NULL,
    -- ...
    INDEX IX_Registration_TenantId (TenantId)  -- 必须索引
);

-- 外键约束
ALTER TABLE Registration
ADD CONSTRAINT FK_Registration_Tenant
FOREIGN KEY (TenantId) REFERENCES Tenant(Id);
```

## 检查清单

- [ ] 所有业务实体实现 `ITenantEntity` 接口
- [ ] 所有查询带租户过滤（推荐全局过滤器）
- [ ] 租户 ID 从 JWT Claim 获取，不从请求参数获取
- [ ] 数据库表包含 `TenantId` 字段和索引
