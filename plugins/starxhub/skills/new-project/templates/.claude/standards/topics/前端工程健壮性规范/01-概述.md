# 前端工程健壮性规范 · 概述

> 基于 Code Review 发现的 C-4、H-6、H-8、H-9、H-10、H-11 等问题提炼。

## 适用范围

本规范适用于所有 Vue 3 + TypeScript 前端代码，特别是类型定义、错误处理、API 调用。

## 核心原则

1. **类型安全原则**：禁止运行时代码出现在 `.d.ts` 文件中
2. **错误分类原则**：区分用户取消、业务错误、系统错误，分别处理
3. **空值防护原则**：所有 API 响应必须做空值检查
4. **用户反馈原则**：错误必须给用户明确的反馈，不能只 console.log

## 问题分类

| 级别 | 说明 | 示例 |
|------|------|------|
| Critical | 导致功能完全失效 | .d.ts 包含运行时代码 |
| High | 导致用户体验差或调试困难 | 错误无反馈、空值未检查 |
| Medium | 代码质量问题 | 类型定义不规范 |

## 强制检查清单

- [ ] `.d.ts` 文件是否只包含类型声明，无运行时代码
- [ ] 文件上传是否删除手动 `Content-Type` 设置
- [ ] API 响应是否做空值防护
- [ ] 错误处理是否区分用户取消和真实错误
- [ ] 错误是否给用户明确的反馈
