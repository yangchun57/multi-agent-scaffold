# 并发与资源管理规范 · 概述

> 基于 Code Review 发现的 H-5、H-7、M-13、M-14、C-2 等问题提炼。

## 适用范围

本规范适用于所有涉及数据库连接、异步操作、并发更新、资源导出的代码。

## 核心原则

1. **资源生命周期原则**：DI 注册的生命周期必须与资源特性匹配
2. **协作取消原则**：所有异步操作必须支持 CancellationToken
3. **并发安全原则**：共享资源的更新必须有并发控制
4. **内存可控原则**：大数据量处理必须使用流式传输，避免内存溢出

## 问题分类

| 级别 | 说明 | 示例 |
|------|------|------|
| Critical | 导致数据损坏或系统崩溃 | DI 生命周期错误、无并发控制 |
| High | 导致资源泄漏或性能问题 | 缺少 CancellationToken、内存溢出 |
| Medium | 潜在风险但影响较小 | 查询逻辑重复 |

## 强制检查清单

- [ ] SqlSugarScope 是否注册为 Singleton
- [ ] Async 方法是否传递 CancellationToken
- [ ] 并发更新是否使用乐观锁或悲观锁
- [ ] 大数据导出是否使用流式传输
- [ ] 唯一性约束是否在数据库层面保证
