# 通用开发规范 · 二、项目结构规范

> 拆分自《通用开发规范》第 2 节。需要全量上下文时读原文件。


### 2.1 后端项目结构

```
src/
└── ProjectName/                          ← 解决方案根目录
    ├── ProjectName.sln                   ← 解决方案文件
    ├── ProjectName.Api/                  ← Web API 主项目（表示层）
    │   ├── Controllers/                    ← 控制器
    │   ├── Filters/                       ← 过滤器（异常、授权）
    │   ├── Extensions/                   ← 扩展方法
    │   ├── Program.cs                     ← 应用入口与 DI 配置
    │   └── appsettings.json               ← 配置文件
    │
    ├── ProjectName.Service/              ← 业务逻辑层
    │   ├── Interfaces/                   ← 服务接口定义
    │   ├── Implementations/              ← 服务实现
    │   └── QueryRequest/                 ← 查询请求 DTO
    │
    ├── ProjectName.Model/                ← 数据模型层
    │   ├── Entities/                     ← 数据库实体
    │   ├── DTOs/
    │   │   ├── Request/                  ← 请求参数 DTO
    │   │   └── Response/                 ← 响应数据 DTO
    │   └── Enums/                         ← 枚举定义
    │
    ├── ProjectName.Common/               ← 公共工具层
    │   ├── ApiResult.cs                  ← 统一返回格式
    │   ├── PageResult.cs                 ← 分页返回
    │   ├── PageRequest.cs                ← 分页请求基类
    │   ├── JwtHelper.cs                  ← JWT 工具
    │   ├── ExcelHelper.cs                ← Excel 工具
    │   ├── BusinessException.cs         ← 业务异常
    │   └── Extensions/                   ← 扩展方法
    │
    └── tests/
        └── ProjectName.Tests/            ← 单元测试项目
            ├── Controllers/               ← Controller 测试
            ├── Services/                 ← Service 测试
            └── Helpers/                  ← 测试辅助类
```

### 2.2 前端项目结构

```
src/
├── api/                 # API 接口定义
│   ├── request.ts       # Axios 实例配置
│   └── {module}.ts      # 按模块划分 API
├── components/          # 公共组件
│   ├── {Component}.vue  # 选择器等通用组件
├── layouts/             # 布局组件
│   └── DefaultLayout.vue
├── router/              # 路由配置
│   └── index.ts
├── stores/              # Pinia 状态管理
│   └── {store}.ts
├── styles/             # 全局样式
│   └── variables.scss
├── types/               # TypeScript 类型定义
│   ├── api.d.ts         # 通用 API 类型
│   ├── enums.ts         # 枚举定义
│   └── {module}.d.ts    # 按模块划分类型
├── utils/               # 工具函数
│   └── {util}.ts
└── views/               # 页面组件
    └── {module}/        # 按业务模块划分
        └── {PageName}.vue
```

### 2.3 项目依赖关系

```
┌─────────────────────┐
│   ProjectName.Api   │ ← 表示层，依赖所有其他项目
└─────────┬───────────┘
           │
           ├──────────────────────┐
           ▼                      ▼
┌─────────────────────┐  ┌──────────────────────┐
│ ProjectName.Service │  │  ProjectName.Common  │
└─────────┬───────────┘  └──────────────────────┘
           │
           ▼
┌─────────────────────┐
│  ProjectName.Model  │
└─────────────────────┘
```
