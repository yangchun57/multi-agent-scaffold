# 并发与资源管理规范 · DI 生命周期规范

> 对应问题：H-5（SqlSugarScope DI 生命周期错误）

## 强制规则

### 1. SqlSugarScope 必须注册为 Singleton

```csharp
// ❌ 错误：注册为 Scoped 或 Transient
builder.Services.AddScoped<ISqlSugarClient>(provider =>
{
    var scope = new SqlSugarScope(new ConnectionConfig
    {
        ConnectionString = connectionString,
        DbType = DbType.SqlServer,
        IsAutoCloseConnection = true
    });
    return scope;
});

// ✅ 正确：注册为 Singleton
builder.Services.AddSingleton<ISqlSugarClient>(provider =>
{
    var scope = new SqlSugarScope(new ConnectionConfig
    {
        ConnectionString = connectionString,
        DbType = DbType.SqlServer,
        IsAutoCloseConnection = true
    });
    
    // 可选：配置 AOP
    scope.Aop.OnLogExecuting = (sql, pars) =>
    {
        Console.WriteLine(sql);
    };
    
    return scope;
});
```

### 2. 理解 SqlSugarScope 的线程安全性

```csharp
// SqlSugarScope 是线程安全的，内部维护连接池
// 每个线程获取独立的连接，无需担心并发问题

// ✅ 正确：在 Service 中注入使用
public class RegistrationService : IRegistrationService
{
    private readonly ISqlSugarClient _db;
    
    public RegistrationService(ISqlSugarClient db)
    {
        _db = db;  // Singleton 注入到 Scoped Service 是安全的
    }
    
    public async Task<List<Registration>> GetAll()
    {
        return await _db.Queryable<Registration>().ToListAsync();
    }
}

// ❌ 错误：每次 new SqlSugarClient
public class RegistrationService
{
    public async Task<List<Registration>> GetAll()
    {
        using var db = new SqlSugarClient(new ConnectionConfig
        {
            ConnectionString = "...",
            DbType = DbType.SqlServer
        });
        return await db.Queryable<Registration>().ToListAsync();
    }
}
```

### 3. 其他 ORM 的生命周期建议

```csharp
// Entity Framework Core
builder.Services.AddDbContext<AppDbContext>(options =>
{
    options.UseSqlServer(connectionString);
}, ServiceLifetime.Scoped);  // DbContext 必须是 Scoped

// Dapper（无状态，可 Singleton）
builder.Services.AddSingleton<IDbConnection>(provider =>
{
    return new SqlConnection(connectionString);
});
```

- [ ] 不在业务代码中直接 new ORM 客户端
