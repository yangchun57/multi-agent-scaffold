# 前端工程健壮性规范 · 空值防护规范

> 对应问题：H-9（多处 API 响应未做空值防护）

## 强制规则

### 1. API 响应必须做空值检查

```typescript
// ❌ 错误：直接访问嵌套属性
async function loadData() {
  const res = await getItem(id)
  detail.value = res.data  // 如果 res.data 为 null，后续访问会报错
}

// 模板中使用
// <div>{{ detail.name }}</div>  // 如果 detail 为 null，报错！

// ✅ 正确：做空值检查
async function loadData() {
  const res = await getItem(id)
  if (res.code === 200 && res.data) {
    detail.value = res.data
  } else {
    ElMessage.error(res.message || '加载失败')
    detail.value = null
  }
}

// 模板中使用可选链
// <div>{{ detail?.name || '未设置' }}</div>
```

### 2. 数组响应必须初始化为空数组

```typescript
// ❌ 错误：未初始化或初始化为 null
const tableData = ref(null)  // 或 let tableData = ref()

async function loadData() {
  const res = await getItems()
  tableData.value = res.data.items  // 如果 items 为 undefined，报错
}

// ✅ 正确：初始化为空数组
const tableData = ref<Item[]>([])

async function loadData() {
  const res = await getItems()
  if (res.code === 200) {
    tableData.value = res.data.items || []  // 兜底空数组
    total.value = res.data.total || 0
  }
}
```

### 3. 对象响应必须提供默认值

```typescript
// ❌ 错误：直接赋值，可能为 null
const userInfo = ref<UserInfo>()

async function loadUserInfo() {
  const res = await getUserInfo()
  userInfo.value = res.data  // 可能为 null
}

// ✅ 正确：提供默认值
const userInfo = ref<UserInfo>({
  id: '',
  name: '',
  phone: '',
  email: ''
})

async function loadUserInfo() {
  const res = await getUserInfo()
  if (res.code === 200 && res.data) {
    userInfo.value = {
      id: res.data.id || '',
      name: res.data.name || '',
      phone: res.data.phone || '',
      email: res.data.email || ''
    }
  }
}
```

### 4. 模板中使用可选链和空值合并

```vue
<template>
  <!-- ❌ 错误：直接访问可能为 null 的属性 -->
  <div>{{ user.name }}</div>
  <div>{{ user.address.city }}</div>
  
  <!-- ✅ 正确：使用可选链 -->
  <div>{{ user?.name || '未设置' }}</div>
  <div>{{ user?.address?.city || '未设置' }}</div>
  
  <!-- ✅ 正确：使用 v-if 判断 -->
  <div v-if="user">{{ user.name }}</div>
  
  <!-- ✅ 正确：使用空值合并 -->
  <div>{{ user?.name ?? '未设置' }}</div>
</template>
```

### 5. 日期格式化必须校验有效性

```typescript
// ❌ 错误：未校验日期有效性
function formatDateTime(dateStr: string) {
  if (!dateStr) return '-'
  return new Date(dateStr).toLocaleString('zh-CN')
  // 如果 dateStr 为 "abc"，返回 "Invalid Date"
}

// ✅ 正确：校验日期有效性
function formatDateTime(dateStr: string) {
  if (!dateStr) return '-'
  
  const date = new Date(dateStr)
  if (isNaN(date.getTime())) {
    console.warn('Invalid date:', dateStr)
    return '-'
  }
  
  return date.toLocaleString('zh-CN')
}
```

## 检查清单

- [ ] API 响应做空值检查（`res.data` 可能为 null）
- [ ] 数组响应初始化为空数组（`ref([])`）
- [ ] 对象响应提供默认值
- [ ] 模板中使用可选链（`?.`）访问可能为 null 的属性
- [ ] 日期格式化校验有效性
- [ ] 使用 `||` 或 `??` 提供兜底值
