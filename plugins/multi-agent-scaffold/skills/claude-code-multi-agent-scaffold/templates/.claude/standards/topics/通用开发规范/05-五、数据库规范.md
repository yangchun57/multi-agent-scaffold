# 通用开发规范 · 五、数据库规范

> 拆分自《通用开发规范》第 5 节。需要全量上下文时读原文件。


### 5.1 命名规范

| 类型 | 命名规则 | 示例 |
|------|---------|------|
| 表名 | lowercase + underscores | `sys_department`, `biz_reading` |
| 主键 | `{Entity}Id` | `dept_id` → `DeptId`, `meter_id` → `MeterId` |
| 外键 | `{RelatedEntity}Id` | `dept_id` (关联 sys_department) |
| 索引 | `idx_{table}_{columns}` | `idx_sys_meter_dept_status` |

### 5.2 SqlSugar 属性

```csharp
[SugarTable("table_name", "表描述")]
public class Entity
{
    [SugarColumn(ColumnName = "id", IsPrimaryKey = true, IsIdentity = true)]
    public long Id { get; set; }

    [SugarColumn(ColumnName = "name", Length = 100)]
    public string Name { get; set; } = string.Empty;

    [SugarColumn(ColumnName = "remark", Length = 500, IsNullable = true)]
    public string? Remark { get; set; }

    [SugarColumn(ColumnName = "created_at")]
    public DateTime CreatedAt { get; set; }

    [SugarColumn(ColumnName = "updated_at")]
    public DateTime UpdatedAt { get; set; }
}
```

### 5.3 通用字段

所有表必须包含：
- `created_at` - 创建时间
- `updated_at` - 更新时间

可空字段使用 C# 可空类型 `?` 配合 `IsNullable = true`
