# 后端开发规范 · 十、日志规范

> 拆分自《后端开发规范》第 10 节。需要全量上下文时读原文件。


### 10.1 Serilog 配置

```csharp
// Program.cs
builder.Host.UseSerilog((context, services, configuration) => configuration
    .ReadFrom.Configuration(context.Configuration)
    .ReadFrom.Services(services)
    .Enrich.FromLogContext()
    .WriteTo.Console()
    .WriteTo.File(
        path: "logs/log-.txt",
        rollingInterval: RollingInterval.Day,
        outputTemplate: "{Timestamp:yyyy-MM-dd HH:mm:ss} [{Level:u3}] {Message:lj}{NewLine}{Exception}"));
```

### 10.2 日志使用规范

```csharp
// 信息日志 - 关键业务操作
_logger.LogInformation("用户 {Username} 登录成功", username);
_logger.LogInformation("创建部门: {DeptCode} - {DeptName}", entity.DeptCode, entity.DeptName);

// 警告日志 - 业务校验失败
_logger.LogWarning("登录失败: 用户名 {Username} 不存在", username);
_logger.LogWarning("删除部门失败: 部门 {DeptId} 下存在仪表", id);

// 错误日志 - 系统异常
_logger.LogError(exception, "处理请求时发生错误: {Message}", exception.Message);
_logger.LogError(exception, "数据库操作失败");
```
