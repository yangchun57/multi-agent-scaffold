### 4.1 实体类规范

#### 4.1.1 实体定义

```csharp
/// <summary>
/// 部门实体
/// </summary>
[SugarTable("sys_department", "部门表")]
public class SysDepartment
{
    /// <summary>
    /// 部门ID
    /// </summary>
    [SugarColumn(ColumnName = "dept_id", IsPrimaryKey = true, IsIdentity = true)]
    public long DeptId { get; set; }

    /// <summary>
    /// 部门编码
    /// </summary>
    [SugarColumn(ColumnName = "dept_code", Length = 20)]
    [Required, MaxLength(20)]
    public string DeptCode { get; set; } = string.Empty;

    /// <summary>
    /// 部门名称
    /// </summary>
    [SugarColumn(ColumnName = "dept_name", Length = 100)]
    [Required, MaxLength(100)]
    public string DeptName { get; set; } = string.Empty;

    /// <summary>
    /// 联系人
    /// </summary>
    [SugarColumn(ColumnName = "contact_person", Length = 50, IsNullable = true)]
    [MaxLength(50)]
    public string? ContactPerson { get; set; }

    /// <summary>
    /// 联系电话
    /// </summary>
    [SugarColumn(ColumnName = "contact_phone", Length = 20, IsNullable = true)]
    [MaxLength(20)]
    public string? ContactPhone { get; set; }

    /// <summary>
    /// 排序号
    /// </summary>
    [SugarColumn(ColumnName = "sort_order")]
    public int SortOrder { get; set; } = 0;

    /// <summary>
    /// 是否启用
    /// </summary>
    [SugarColumn(ColumnName = "is_enabled")]
    public bool IsEnabled { get; set; } = true;

    /// <summary>
    /// 备注
    /// </summary>
    [SugarColumn(ColumnName = "remark", Length = 500, IsNullable = true)]
    [MaxLength(500)]
    public string? Remark { get; set; }

    /// <summary>
    /// 创建时间
    /// </summary>
    [SugarColumn(ColumnName = "created_at")]
    public DateTime CreatedAt { get; set; } = DateTime.Now;

    /// <summary>
    /// 更新时间
    /// </summary>
    [SugarColumn(ColumnName = "updated_at")]
    public DateTime UpdatedAt { get; set; } = DateTime.Now;
}
```

#### 4.1.2 实体命名规范

| 规则 | 说明 | 示例 |
|------|------|------|
| 表名前缀 | sys_ 系统基础、biz_ 业务、cfg_ 配置、res_ 住宅 | `sys_department`, `biz_reading` |
| 实体类名 | PascalCase，去掉前缀，使用 Sys/Biz/Cfg/Res 前缀 | `SysDepartment`, `BizReading` |
| 主键命名 | {表名单数}_id | `dept_id`, `meter_id` |
| 外键命名 | 关联表名_id | `dept_id` (关联 sys_department) |

#### 4.2.1 请求 DTO

```csharp
// ===== 查询参数 =====

public class DepartmentQueryRequest : PageQueryRequest

/// <summary>
/// 分页查询基类
/// </summary>
public abstract class PageQueryRequest
{
    /// <summary>
    /// 页码（从1开始）
    /// </summary>
    [Range(1, int.MaxValue)]
    public int PageIndex { get; set; } = 1;

    /// <summary>
    /// 每页条数
    /// </summary>
    [Range(1, 100)]
    public int PageSize { get; set; } = 20;
}

// ===== 创建请求 =====

/// <summary>
/// 创建部门请求
/// </summary>
public class DepartmentCreateRequest
{
    /// <summary>
    /// 部门编码
    /// </summary>
    [Required(ErrorMessage = "部门编码不能为空")]
    [MaxLength(20, ErrorMessage = "部门编码最长20个字符")]
    public string DeptCode { get; set; } = string.Empty;

    /// <summary>
    /// 部门名称
    /// </summary>
    [Required(ErrorMessage = "部门名称不能为空")]
    [MaxLength(100, ErrorMessage = "部门名称最长100个字符")]
    public string DeptName { get; set; } = string.Empty;

    /// <summary>
    /// 联系人
    /// </summary>
    [MaxLength(50)]
    public string? ContactPerson { get; set; }

    /// <summary>
    /// 联系电话
    /// </summary>
    [MaxLength(20)]
    [Phone(ErrorMessage = "联系电话格式不正确")]
    public string? ContactPhone { get; set; }

    /// <summary>
    /// 排序号
    /// </summary>
    public int? SortOrder { get; set; }

    /// <summary>
    /// 备注
    /// </summary>
    [MaxLength(500)]
    public string? Remark { get; set; }
}

// ===== 更新请求 =====

/// <summary>
/// 更新部门请求
/// </summary>
public class DepartmentUpdateRequest : DepartmentCreateRequest
{
    // 更新时通常继承创建请求，业务逻辑层设置 ID
}
```

### 4.4 JSON 序列化与前后端字段映射规范

#### 4.4.1 JSON 序列化策略

ASP.NET Core 默认使用 `System.Text.Json`，将 C# `PascalCase` 属性自动序列化为 `camelCase` JSON 字段。项目必须保持此默认行为，禁止手动更改序列化策略。

```csharp
// Program.cs - 默认配置（无需额外设置）
builder.Services.AddControllers();
// 默认 PropertyNamingPolicy = JsonNamingPolicy.CamelCase
```

#### 4.4.2 DTO 字段命名约束

- 后端 DTO 属性名使用 `PascalCase`，前端 JSON 中自动变为 `camelCase`
- 响应 DTO 字段名应与数据库字段含义一一对应，不得随意改名
- 禁止在 DTO 中使用 `[JsonPropertyName("xxx")]` 手动覆盖字段名（除非有特殊业务需求并经过评审）

#### 4.4.3 字段映射示例

| 后端 C# 属性 (PascalCase) | 前端 JSON 字段 (camelCase) | 说明 |
|--------------------------|--------------------------|------|
| `RoomId` | `roomId` | 主键 |
| `RoomName` | `roomName` | 普通字段 |
| `BuildingId` | `buildingId` | 外键 |
| `QrCodeUrl` | `qrCodeUrl` | 缩写词也遵循 camelCase |
| `IsReservable` | `isReservable` | 布尔字段 |
| `CreatedAt` | `createdAt` | 时间字段 |

#### 4.4.4 更新请求 DTO 必须包含完整字段

更新请求 DTO 必须包含所有可修改字段的属性，禁止遗漏。前端提交更新时，后端根据请求中的字段逐一赋值到实体。

```csharp
// 正确：更新请求包含所有可修改字段
public class RoomUpdateRequest
{
    public long RoomId { get; set; }
    public string RoomName { get; set; } = string.Empty;
    public long BuildingId { get; set; }    // 必须包含
    public long FloorId { get; set; }       // 必须包含
    public int Capacity { get; set; }
    public string? Devices { get; set; }
    public string? Remark { get; set; }
}

// 错误：更新请求缺少 BuildingId/FloorId，导致编辑时无法修改这些字段
```
