# 后端开发规范 · 十四、代码审查清单

> 拆分自《后端开发规范》第 14 节。需要全量上下文时读原文件。


### 14.1 Controller 审查

- [ ] 路由是否规范（RESTful 风格）
- [ ] 权限特性是否正确配置
- [ ] 参数校验特性是否完整
- [ ] 是否返回统一格式的 ApiResult
- [ ] 是否正确使用异步方法

### 14.2 Service 审查

- [ ] 是否通过接口注入依赖
- [ ] 是否正确处理业务异常
- [ ] 事务是否正确使用
- [ ] 是否有足够的日志记录
- [ ] 是否正确使用 async/await

### 14.3 数据访问审查

- [ ] 是否使用参数化查询（防止 SQL 注入）
- [ ] 是否正确处理空值
- [ ] 分页查询是否高效
- [ ] 是否有必要的索引支持

### 14.4 安全审查

- [ ] 敏感数据是否加密存储
- [ ] 密码是否使用 BCrypt 哈希
- [ ] 是否有越权访问风险
- [ ] 输入是否经过校验和清理
