# 后端开发规范 · 二、项目结构规范

> 拆分自《后端开发规范》第 2 节。需要全量上下文时读原文件。


### 2.1 解决方案结构

```
src/
└── HNU.WaterElec/                          ← 解决方案根目录
    ├── HNU.WaterElec.sln                   ← 解决方案文件
    ├── HNU.WaterElec.Api/                  ← Web API 主项目（表示层）
    │   ├── Controllers/                    ← 控制器
    │   ├── Filters/                        ← 过滤器（异常、授权）
    │   ├── Extensions/                     ← 扩展方法
    │   ├── Program.cs                      ← 应用入口与 DI 配置
    │   └── appsettings.json                ← 配置文件
    │
    ├── HNU.WaterElec.Service/              ← 业务逻辑层
    │   ├── Interfaces/                     ← 服务接口定义
    │   └── Implementations/                ← 服务实现
    │
    ├── HNU.WaterElec.Model/                ← 数据模型层
    │   ├── Entities/                       ← 数据库实体
    │   ├── DTOs/
    │   │   ├── Request/                    ← 请求参数 DTO
    │   │   └── Response/                   ← 响应数据 DTO
    │   └── Enums/                          ← 枚举定义
    │
    ├── HNU.WaterElec.Common/               ← 公共工具层
    │   ├── ApiResult.cs                    ← 统一返回格式
    │   ├── PageResult.cs                   ← 分页返回
    │   ├── JwtHelper.cs                    ← JWT 工具
    │   ├── ExcelHelper.cs                  ← Excel 工具
    │   └── Extensions/                     ← 扩展方法
    │
    └── tests/
        └── HNU.WaterElec.Tests/            ← 单元测试项目
```

### 2.2 项目依赖关系

```
┌─────────────────────┐
│  HNU.WaterElec.Api  │ ← 表示层，依赖所有其他项目
└─────────┬───────────┘
          │
          ├──────────────────────┐
          ▼                      ▼
┌─────────────────────┐  ┌──────────────────────┐
│ HNU.WaterElec.Service│  │ HNU.WaterElec.Common │
└─────────┬───────────┘  └──────────────────────┘
          │
          ▼
┌─────────────────────┐
│  HNU.WaterElec.Model │
└─────────────────────┘
```

**依赖原则**：
- Api 项目依赖 Service、Model、Common
- Service 项目依赖 Model、Common
- Model 项目无外部依赖
- Common 项目无业务依赖
