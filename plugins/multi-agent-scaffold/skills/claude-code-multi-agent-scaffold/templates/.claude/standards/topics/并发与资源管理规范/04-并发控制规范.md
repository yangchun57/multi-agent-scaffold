# 并发与资源管理规范 · 并发控制规范

> 对应问题：M-14（并发更新无控制）、C-2（手机号唯一性竞态条件）

## 强制规则

### 1. 数据库层面保证唯一性

```sql
-- ✅ 正确：数据库唯一约束
CREATE TABLE Registration (
    Id BIGINT PRIMARY KEY,
    TenantId BIGINT NOT NULL,
    Phone NVARCHAR(20) NOT NULL,
    Name NVARCHAR(100) NOT NULL,
    -- ...
    CONSTRAINT UQ_Registration_Tenant_Phone UNIQUE (TenantId, Phone)
);

-- 索引
CREATE UNIQUE INDEX IX_Registration_Tenant_Phone
ON Registration (TenantId, Phone);
```

```csharp
// Service 层捕获唯一约束异常
public async Task<long> Create(Registration entity, CancellationToken cancellationToken = default)
{
    try
    {
        return await _db.Insertable(entity)
            .ExecuteReturnSnowflakeIdAsync(cancellationToken);
    }
    catch (SqlSugarException ex) when (ex.Message.Contains("UNIQUE") || ex.ErrorCode == 2627)
    {
        throw new BusinessException($"手机号 {entity.Phone} 已存在", 409);
    }
}
```

### 2. 乐观锁（推荐：适合低冲突场景）

```csharp
// 实体添加 RowVersion 字段
public class CompanyInfo : ITenantEntity
{
    public long Id { get; set; }
    public string CompanyName { get; set; }
    public string LogoUrl { get; set; }
    
    // ✅ 乐观锁字段
    [SugarColumn(IsOnlyIgnoreInsert = true, IsOnlyIgnoreUpdate = false)]
    public byte[] RowVersion { get; set; }
}

// SQL Server 表结构
/*
CREATE TABLE CompanyInfo (
    Id BIGINT PRIMARY KEY,
    TenantId BIGINT NOT NULL,
    CompanyName NVARCHAR(200) NOT NULL,
    LogoUrl NVARCHAR(500),
    RowVersion ROWVERSION NOT NULL  -- 自动递增
);
*/

// Service 更新方法
public async Task<bool> Update(CompanyInfo entity, CancellationToken cancellationToken = default)
{
    var result = await _db.Updateable(entity)
        .WhereColumns(it => new { it.Id, it.RowVersion })  // 包含 RowVersion
        .ExecuteCommandAsync(cancellationToken);
    
    if (result == 0)
    {
        throw new BusinessException("数据已被其他用户修改，请刷新后重试", 409);
    }
    
    return true;
}
```

### 3. 悲观锁（适合高冲突场景）

```csharp
// 使用数据库事务 + SELECT FOR UPDATE
public async Task<bool> UpdateWithLock(long id, Action<CompanyInfo> updateAction, 
    CancellationToken cancellationToken = default)
{
    try
    {
        _db.Ado.BeginTran();
        
        // 悲观锁：SELECT FOR UPDATE
        var entity = await _db.Queryable<CompanyInfo>()
            .Where(c => c.Id == id)
            .With(SqlWith.UpdLock)  // SqlSugar 的悲观锁语法
            .FirstAsync(cancellationToken);
        
        if (entity == null)
        {
            throw new NotFoundException("企业信息", id);
        }
        
        updateAction(entity);
        
        await _db.Updateable(entity).ExecuteCommandAsync(cancellationToken);
        _db.Ado.CommitTran();
        return true;
    }
    catch
    {
        _db.Ado.RollbackTran();
        throw;
    }
}
```

### 4. 前端并发冲突处理

```typescript
// ✅ 正确：处理 409 冲突
async function handleSave() {
  saving.value = true
  try {
    if (form.value.id) {
      await updateCompanyInfo(form.value.id, form.value)
      ElMessage.success('保存成功')
    } else {
      await createCompanyInfo(form.value)
      ElMessage.success('创建成功')
    }
    dialogVisible.value = false
    await loadData()
  } catch (error) {
    if (axios.isAxiosError(error) && error.response?.status === 409) {
      ElMessageBox.confirm(
        '数据已被其他用户修改，是否刷新页面获取最新数据？',
        '冲突提示',
        {
          confirmButtonText: '刷新',
          cancelButtonText: '取消',
          type: 'warning'
        }
      ).then(() => {
        loadData()
      })
    } else {
      ElMessage.error('保存失败')
    }
  } finally {
    saving.value = false
  }
}
```
