### 9.1 组件懒加载

```typescript
// 路由懒加载
component: () => import('@/views/family/FamilyMeterList.vue')

// 大组件懒加载
const HeavyComponent = defineAsyncComponent(() =>
  import('@/components/HeavyComponent.vue')
)
```

### 9.2 列表虚拟滚动

大数据量列表使用虚拟滚动：

```vue
<el-table-v2
  :columns="columns"
  :data="data"
  :width="700"
  :height="400"
/>
```

### 9.3 防抖和节流

```typescript
import { debounce, throttle } from 'lodash-es'

// 搜索输入防抖
const handleSearch = debounce(() => {
  loadData()
}, 300)

// 滚动节流
const handleScroll = throttle(() => {
  // 处理滚动
}, 200)
```
