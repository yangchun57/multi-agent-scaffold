# 安全编码规范 · 文件上传安全规范

> 对应问题：H-2（文件上传无大小/类型校验）

## 强制规则

### 1. 文件大小限制

```csharp
// Program.cs
builder.Services.Configure<FormOptions>(options =>
{
    options.MultipartBodyLengthLimit = 10 * 1024 * 1024; // 10 MB
});

// Controller
[HttpPost("upload")]
public async Task<ApiResult<string>> Upload(IFormFile file)
{
    // ✅ 强制：校验文件大小
    const long maxFileSize = 5 * 1024 * 1024; // 5 MB
    if (file.Length > maxFileSize)
    {
        return ApiResult.Fail<string>("文件大小不能超过 5MB");
    }
    
    // 继续处理...
}
```

### 2. 文件类型校验（MIME + 扩展名双重校验）

```csharp
// 允许的 MIME 类型
private static readonly HashSet<string> AllowedMimeTypes = new()
{
    "image/jpeg",
    "image/png",
    "image/gif",
    "application/pdf"
};

// 允许的扩展名
private static readonly HashSet<string> AllowedExtensions = new(StringComparer.OrdinalIgnoreCase)
{
    ".jpg", ".jpeg", ".png", ".gif", ".pdf"
};

[HttpPost("upload")]
public async Task<ApiResult<string>> Upload(IFormFile file)
{
    // ✅ 强制：MIME 类型校验
    if (!AllowedMimeTypes.Contains(file.ContentType))
    {
        return ApiResult.Fail<string>($"不支持的文件类型: {file.ContentType}");
    }
    
    // ✅ 强制：扩展名校验
    var extension = Path.GetExtension(file.FileName);
    if (!AllowedExtensions.Contains(extension))
    {
        return ApiResult.Fail<string>($"不支持的文件扩展名: {extension}");
    }
    
    // ✅ 推荐：读取文件头校验魔数（防止伪造扩展名）
    using var stream = file.OpenReadStream();
    var header = new byte[8];
    await stream.ReadAsync(header);
    
    if (!IsValidFileHeader(header, extension))
    {
        return ApiResult.Fail<string>("文件内容与扩展名不匹配");
    }
    
    // 继续处理...
}

private bool IsValidFileHeader(byte[] header, string extension)
{
    return extension.ToLower() switch
    {
        ".jpg" or ".jpeg" => header[0] == 0xFF && header[1] == 0xD8,
        ".png" => header[0] == 0x89 && header[1] == 0x50,
        ".gif" => header[0] == 0x47 && header[1] == 0x49,
        ".pdf" => header[0] == 0x25 && header[1] == 0x50,
        _ => false
    };
}
```

### 3. 文件存储安全

```csharp
// ✅ 正确：使用随机文件名，不保留原始文件名
var fileName = $"{Guid.NewGuid()}{extension}";
var filePath = Path.Combine(uploadPath, fileName);

using (var stream = new FileStream(filePath, FileMode.Create))
{
    await file.CopyToAsync(stream);
}

// ❌ 错误：直接使用用户上传的文件名
var filePath = Path.Combine(uploadPath, file.FileName); // 可能包含路径穿越攻击
```

### 4. 前端上传规范

```typescript
// ✅ 正确：让浏览器自动设置 Content-Type（multipart/form-data + boundary）
async function uploadFile(file: File) {
  const formData = new FormData()
  formData.append('file', file)
  
  // ❌ 禁止：手动设置 Content-Type
  // const res = await axios.post('/api/upload', formData, {
  //   headers: { 'Content-Type': 'multipart/form-data' }  // 错误！
  // })
  
  // ✅ 正确：不设置 Content-Type，让浏览器自动处理
  const res = await axios.post('/api/upload', formData)
  return res.data
}

// ✅ 强制：前端也做大小校验
const MAX_FILE_SIZE = 5 * 1024 * 1024 // 5 MB

function validateFile(file: File): string | null {
  if (file.size > MAX_FILE_SIZE) {
    return `文件大小不能超过 5MB`
  }
  
  const allowedTypes = ['image/jpeg', 'image/png', 'image/gif', 'application/pdf']
  if (!allowedTypes.includes(file.type)) {
    return `不支持的文件类型: ${file.type}`
  }
  
  return null
}
```

## 完整示例

```csharp
[HttpPost("upload")]
[RequestSizeLimit(10 * 1024 * 1024)] // 整个请求最大 10MB
public async Task<ApiResult<string>> Upload(IFormFile file)
{
    // 1. 校验文件大小
    const long maxFileSize = 5 * 1024 * 1024;
    if (file.Length > maxFileSize)
    {
        return ApiResult.Fail<string>("文件大小不能超过 5MB");
    }
    
    // 2. 校验 MIME 类型
    var allowedMimeTypes = new[] { "image/jpeg", "image/png", "application/pdf" };
    if (!allowedMimeTypes.Contains(file.ContentType))
    {
        return ApiResult.Fail<string>($"不支持的文件类型: {file.ContentType}");
    }
    
    // 3. 校验扩展名
    var extension = Path.GetExtension(file.FileName);
    var allowedExtensions = new[] { ".jpg", ".jpeg", ".png", ".pdf" };
    if (!allowedExtensions.Contains(extension.ToLower()))
    {
        return ApiResult.Fail<string>($"不支持的文件扩展名: {extension}");
    }
    
    // 4. 生成安全文件名
    var fileName = $"{Guid.NewGuid()}{extension}";
    var filePath = Path.Combine(_uploadPath, fileName);
    
    // 5. 保存文件
    using (var stream = new FileStream(filePath, FileMode.Create))
    {
        await file.CopyToAsync(stream);
    }
    
    return ApiResult.Ok(fileName);
}
```

## 检查清单

- [ ] 后端校验文件大小（≤ 10MB）
- [ ] 后端校验 MIME 类型（白名单）
- [ ] 后端校验文件扩展名（白名单）
- [ ] 使用随机文件名，不保留原始文件名
- [ ] 前端也做大小和类型校验（提升用户体验）
- [ ] 前端不手动设置 `Content-Type: multipart/form-data`
