# 并发与资源管理规范 · 流式导出规范

> 对应问题：H-7（导出功能内存溢出风险）

## 强制规则

### 1. 大数据量导出必须使用流式传输

```csharp
// ❌ 错误：一次性加载所有数据到内存
[HttpGet("export")]
public async Task<IActionResult> Export()
{
    var allData = await _db.Queryable<Registration>().ToListAsync();  // 内存溢出！
    var bytes = ExcelHelper.Export(allData);
    return File(bytes, "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet", "export.xlsx");
}

// ✅ 正确：流式查询 + 流式写入
[HttpGet("export")]
public async Task<IActionResult> Export()
{
    var stream = new MemoryStream();
    
    using (var package = new ExcelPackage())
    {
        var worksheet = package.Workbook.Worksheets.Add("Registrations");
        
        // 写入表头
        worksheet.Cells[1, 1].Value = "姓名";
        worksheet.Cells[1, 2].Value = "手机号";
        worksheet.Cells[1, 3].Value = "创建时间";
        
        int row = 2;
        const int pageSize = 1000;
        int pageIndex = 1;
        
        // ✅ 分页查询，避免内存溢出
        while (true)
        {
            var page = await _db.Queryable<Registration>()
                .OrderBy(r => r.Id)
                .ToPageListAsync(pageIndex, pageSize);
            
            if (page.Count == 0) break;
            
            foreach (var item in page)
            {
                worksheet.Cells[row, 1].Value = item.Name;
                worksheet.Cells[row, 2].Value = item.Phone;
                worksheet.Cells[row, 3].Value = item.CreatedAt;
                row++;
            }
            
            pageIndex++;
        }
        
        package.SaveAs(stream);
    }
    
    stream.Position = 0;
    return File(stream, "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet", "export.xlsx");
}
```

### 2. 超大数据量使用 CSV 格式

```csharp
// ✅ 对于超大数据量（>10万行），推荐 CSV 格式
[HttpGet("export-csv")]
public async Task<IActionResult> ExportCsv()
{
    var stream = new MemoryStream();
    using var writer = new StreamWriter(stream, Encoding.UTF8);
    
    // 写入 BOM（Excel 识别 UTF-8）
    await writer.WriteAsync("\uFEFF");
    
    // 写入表头
    await writer.WriteLineAsync("姓名,手机号,创建时间");
    
    // 流式查询
    const int pageSize = 1000;
    int pageIndex = 1;
    
    while (true)
    {
        var page = await _db.Queryable<Registration>()
            .OrderBy(r => r.Id)
            .ToPageListAsync(pageIndex, pageSize);
        
        if (page.Count == 0) break;
        
        foreach (var item in page)
        {
            await writer.WriteLineAsync($"{item.Name},{item.Phone},{item.CreatedAt}");
        }
        
        pageIndex++;
    }
    
    await writer.FlushAsync();
    stream.Position = 0;
    
    return File(stream, "text/csv", "export.csv");
}
```

### 3. 前端下载大文件

```typescript
// ✅ 正确：使用 Blob 下载
async function handleExport() {
  exporting.value = true
  try {
    const res = await axios.get('/api/registrations/export', {
      responseType: 'blob'  // 必须设置
    })
    
    const blob = new Blob([res.data], {
      type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
    })
    
    const url = window.URL.createObjectURL(blob)
    const link = document.createElement('a')
    link.href = url
    link.download = `导出_${new Date().toLocaleDateString()}.xlsx`
    link.click()
    
    window.URL.revokeObjectURL(url)
    ElMessage.success('导出成功')
  } catch (error) {
    ElMessage.error('导出失败')
  } finally {
    exporting.value = false
  }
}
```

## 检查清单

- [ ] 大数据量导出使用分页查询，不一次性加载
- [ ] 超大数据量（>10万行）使用 CSV 格式
- [ ] 前端使用 Blob 下载，设置 `responseType: 'blob'`
- [ ] 导出功能添加进度提示（可选）
