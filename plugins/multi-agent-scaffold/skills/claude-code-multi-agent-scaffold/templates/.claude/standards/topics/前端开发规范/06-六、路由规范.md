# 前端开发规范 · 六、路由规范

> 拆分自《前端开发规范》第 6 节。需要全量上下文时读原文件。


### 6.1 路由结构

```typescript
const routes: RouteRecordRaw[] = [
  {
    path: '/',
    component: () => import('@/layouts/DefaultLayout.vue'),
    redirect: '/dashboard',
    children: [
      {
        path: 'dashboard',
        name: 'Dashboard',
        component: () => import('@/views/dashboard/DashboardView.vue'),
        meta: { title: '首页看板', icon: 'Odometer', roles: ['admin', 'reader'] },
      },
      // 业务模块...
    ],
  },
]
```

### 6.2 路由命名

| 层级 | 命名规则 | 示例 |
|------|---------|------|
| 一级菜单 | {Module}Parent | `UnitParent`, `FamilyParent` |
| 二级菜单 | {SubModule}Parent | `UnitMeterParent`, `FamilyBaseParent` |
| 页面 | PascalCase | `MeterList`, `FamilyBillingList` |

### 6.3 Meta 字段

```typescript
meta: {
  title: string,          // 菜单标题
  icon?: string,          // 菜单图标
  roles?: string[],       // 允许的角色
  hidden?: boolean,       // 是否隐藏菜单
  requiresAuth?: boolean, // 是否需要登录
}
```

### 6.4 懒加载

所有页面组件使用动态导入：

```typescript
component: () => import('@/views/family/FamilyMeterList.vue')
```
