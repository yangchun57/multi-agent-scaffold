# 通用开发规范

> **加载提示**：本文件较大，日常按需读取——先读 `topics/INDEX.md` 定位主题，或用 Grep 搜关键词后按行号局部读取（Read offset/limit）。仅需要全量核对时才整读本文件。

> 本规范基于实际项目经验整理，适用于 .NET 8 + Vue 3 技术栈的 Web 应用开发。


### 1.1 后端技术选型

| 层面 | 技术选型 | 版本 | 说明 |
|------|---------|------|------|
| 后端框架 | ASP.NET Core Web API | .NET 8 | Controller 模式，RESTful API |
| ORM | SqlSugar | 5.x | 国产 ORM，对 MySQL 支持完善 |
| 数据库 | MySQL | 8.0+ | InnoDB 引擎，utf8mb4 字符集 |
| 认证 | JWT Bearer Token | — | 无状态 Token 认证 |
| Excel 处理 | MiniExcel | — | 轻量高性能 Excel 读写 |
| 密码加密 | BCrypt.Net | — | 密码哈希 |
| 依赖注入 | Microsoft.Extensions.DependencyInjection | — | .NET 内置 DI 容器 |
| 日志 | Serilog | — | 结构化日志 |
| API 文档 | Swagger/Swashbuckle | — | API 自动文档生成 |

### 1.2 前端技术选型

| 层面 | 技术选型 | 说明 |
|------|---------|------|
| 框架 | Vue 3 | Composition API + `<script setup>` |
| UI 组件库 | Element Plus | Element UI 的 Vue 3 版本 |
| 状态管理 | Pinia | Vue 3 推荐的状态管理 |
| 路由 | Vue Router | 动态路由 + 懒加载 |
| HTTP 客户端 | Axios | 请求拦截 + 响应拦截 |
| 构建工具 | Vite | 快速开发体验 |
| 语言 | TypeScript | 强类型支持 |
