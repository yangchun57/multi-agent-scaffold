# 后端开发规范 · 三、分层架构规范

> 拆分自《后端开发规范》第 3 节。需要全量上下文时读原文件。


### 3.1 各层职责

| 层 | 命名空间 | 职责 | 禁止事项 |
|---|---------|------|---------|
| Controller | HNU.WaterElec.Api.Controllers | 参数接收与校验、权限控制、调用 Service、返回统一响应 | 禁止包含任何业务逻辑 |
| Service | HNU.WaterElec.Service | 所有业务逻辑、数据验证、事务管理、分摊/费用计算 | 禁止直接操作 HttpContext |
| Model | HNU.WaterElec.Model | 数据库实体映射、DTO 定义、枚举定义 | 禁止包含业务逻辑方法 |
| Common | HNU.WaterElec.Common | 公共工具类（JWT、Excel、统一返回格式等） | 禁止引用 Service 或 Model |

### 3.2 Controller 层规范

#### 3.2.1 基本结构

```csharp
/// <summary>
/// 部门管理控制器
/// </summary>
[ApiController]
[Route("api/[controller]")]
public class DepartmentController : ControllerBase
{
    private readonly IDepartmentService _departmentService;
    private readonly ILogger<DepartmentController> _logger;

    public DepartmentController(
        IDepartmentService departmentService,
        ILogger<DepartmentController> logger)
    {
        _departmentService = departmentService;
        _logger = logger;
    }

    /// <summary>
    /// 获取部门列表（分页）
    /// </summary>
    [HttpGet]
    [Authorize] // 所有已认证用户
    public async Task<ActionResult<ApiResult<PageResult<DepartmentDto>>>> GetList(
        [FromQuery] DepartmentQueryRequest request)
    {
        var result = await _departmentService.GetPagedListAsync(request);
        return Ok(ApiResult<PageResult<DepartmentDto>>.Success(result));
    }

    /// <summary>
    /// 获取全部部门（不分页）
    /// </summary>
    [HttpGet("all")]
    [Authorize]
    public async Task<ActionResult<ApiResult<List<DepartmentSimpleDto>>>> GetAll()
    {
        var result = await _departmentService.GetAllAsync();
        return Ok(ApiResult<List<DepartmentSimpleDto>>.Success(result));
    }

    /// <summary>
    /// 获取部门详情
    /// </summary>
    [HttpGet("{id}")]
    [Authorize]
    public async Task<ActionResult<ApiResult<DepartmentDto>>> GetById(long id)
    {
        var result = await _departmentService.GetByIdAsync(id);
        if (result == null)
        {
            return Ok(ApiResult<DepartmentDto>.Fail("部门不存在", 404));
        }
        return Ok(ApiResult<DepartmentDto>.Success(result));
    }

    /// <summary>
    /// 新增部门
    /// </summary>
    [HttpPost]
    [Authorize(Roles = "admin")]
    public async Task<ActionResult<ApiResult<DepartmentDto>>> Create(
        [FromBody] DepartmentCreateRequest request)
    {
        var result = await _departmentService.CreateAsync(request);
        return Ok(ApiResult<DepartmentDto>.Success(result, "创建成功"));
    }

    /// <summary>
    /// 编辑部门
    /// </summary>
    [HttpPut("{id}")]
    [Authorize(Roles = "admin")]
    public async Task<ActionResult<ApiResult<DepartmentDto>>> Update(
        long id, [FromBody] DepartmentUpdateRequest request)
    {
        request.DeptId = id;
        var result = await _departmentService.UpdateAsync(request);
        return Ok(ApiResult<DepartmentDto>.Success(result, "更新成功"));
    }

    /// <summary>
    /// 删除部门
    /// </summary>
    [HttpDelete("{id}")]
    [Authorize(Roles = "admin")]
    public async Task<ActionResult<ApiResult<object>>> Delete(long id)
    {
        await _departmentService.DeleteAsync(id);
        return Ok(ApiResult<object>.Success(null, "删除成功"));
    }
}
```

#### 3.2.2 Controller 规范要点

1. **路由规范**
   - 使用 `[ApiController]` 特性
   - 路由模板使用 `[Route("api/[controller]")]`
   - 子资源路由使用 RESTful 风格：`api/meters/{meterId}/sharings`

2. **权限控制**
   - 所有需要认证的接口添加 `[Authorize]`
   - 按角色控制使用 `[Authorize(Roles = "admin,finance")]`
   - 公开接口（如登录）不添加认证特性

3. **参数来源**
   - 查询参数使用 `[FromQuery]`
   - 路径参数使用路由模板参数
   - 请求体使用 `[FromBody]`
   - 表单数据使用 `[FromForm]`

4. **响应格式**
   - 统一使用 `ApiResult<T>` 包装响应
   - 成功：`ApiResult<T>.Success(data, message)`
   - 失败：`ApiResult<T>.Fail(message, code)`

### 3.3 Service 层规范

#### 3.3.1 接口定义

#### 3.3.2 服务实现

```csharp
/// <summary>
/// 部门服务实现
/// </summary>
public class DepartmentService : IDepartmentService
{
    private readonly ISqlSugarClient _db;
    private readonly ILogger<DepartmentService> _logger;

    public DepartmentService(ISqlSugarClient db, ILogger<DepartmentService> logger)
    {
        _db = db;
        _logger = logger;
    }

    public async Task<PageResult<DepartmentDto>> GetPagedListAsync(DepartmentQueryRequest request)
    {
        var query = _db.Queryable<SysDepartment>()
            .WhereIF(!string.IsNullOrEmpty(request.Keyword),
                d => d.DeptCode.Contains(request.Keyword!) ||
                     d.DeptName.Contains(request.Keyword!))
            .WhereIF(request.IsEnabled.HasValue,
                d => d.IsEnabled == request.IsEnabled);

        var total = await query.CountAsync();

        var items = await query
            .OrderBy(d => d.SortOrder)
            .OrderBy(d => d.DeptId)
            .Skip((request.PageIndex - 1) * request.PageSize)
            .Take(request.PageSize)
            .Select<DepartmentDto>()
            .ToListAsync();

        return new PageResult<DepartmentDto>
        {
            Items = items,
            Total = total,
            PageIndex = request.PageIndex,
            PageSize = request.PageSize
        };
    }

    public async Task<DepartmentDto> CreateAsync(DepartmentCreateRequest request)
    {
        // 校验部门编码唯一性
        var exists = await _db.Queryable<SysDepartment>()
            .Where(d => d.DeptCode == request.DeptCode)
            .FirstAsync();

        if (exists != null)
        {
            throw new BusinessException("部门编码已存在");
        }

        var entity = new SysDepartment
        {
            DeptCode = request.DeptCode,
            DeptName = request.DeptName,
            ContactPerson = request.ContactPerson,
            ContactPhone = request.ContactPhone,
            SortOrder = request.SortOrder ?? 0,
            Remark = request.Remark,
            IsEnabled = true
        };

        await _db.Insertable(entity).ExecuteCommandAsync();

        _logger.LogInformation("创建部门: {DeptCode} - {DeptName}",
            entity.DeptCode, entity.DeptName);

        return await GetByIdAsync(entity.DeptId);
    }

    public async Task DeleteAsync(long id)
    {
        // 检查是否有仪表关联
        var meterCount = await _db.Queryable<SysMeter>()
            .Where(m => m.DeptId == id)
            .CountAsync();

        if (meterCount > 0)
        {
            throw new BusinessException("该部门下存在仪表，无法删除");
        }

        var result = await _db.Deleteable<SysDepartment>()
            .Where(d => d.DeptId == id)
            .ExecuteCommandAsync();

        if (result == 0)
        {
            throw new BusinessException("部门不存在");
        }

        _logger.LogInformation("删除部门: {DeptId}", id);
    }
}
```

#### 3.3.3 Service 规范要点

1. **依赖注入**
   - 通过构造函数注入 `ISqlSugarClient`
   - 注入所需的其他 Service（避免循环依赖）
   - 注入 `ILogger<T>` 用于日志记录

2. **事务管理**
   ```csharp
   public async Task<long> CalculateBillingAsync(string period, bool overwrite)
   {
       var result = await _db.Ado.UseTranAsync(async () =>
       {
           // 事务内的所有操作
           var readings = await GetConfirmedReadingsAsync(period);
           foreach (var reading in readings)
           {
               await CreateBillingAsync(reading);
           }
       });

       if (!result.IsSuccess)
       {
           throw new BusinessException($"费用计算失败: {result.ErrorMessage}");
       }

       return result.Data;
   }
   ```

3. **业务异常**
   - 抛出 `BusinessException` 表示业务校验失败
   - 包含明确的错误信息，便于前端展示

4. **日志记录**
   - 关键操作记录 Info 级别日志
   - 异常记录 Error 级别日志
   - 使用结构化日志格式
