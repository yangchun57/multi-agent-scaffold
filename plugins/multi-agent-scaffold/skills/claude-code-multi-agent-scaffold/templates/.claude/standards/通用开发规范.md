## 三、后端开发规范

### 3.1 命名规范

| 类型 | 命名规则 | 示例 |
|------|---------|------|
| Controller | `{Entity}Controller` | `DepartmentController`, `MeterController` |
| Service 接口 | `I{Entity}Service` | `IDepartmentService`, `IMeterService` |
| Service 实现 | `{Entity}Service` | `DepartmentService`, `MeterService` |
| 实体类 | `Sys{Entity}` / `Biz{Entity}` / `Res{Entity}` / `Cfg{Entity}` | `SysDepartment`, `BizReading`, `ResCommunity` |
| 私有字段 | `_camelCase` | `_departmentService`, `_db`, `_logger` |
| 异步方法 | `{Action}Async` | `GetByIdAsync`, `CreateAsync`, `UpdateAsync` |
| 查询请求 | `{Entity}QueryRequest` | `DepartmentQueryRequest` |
| 创建请求 | `{Entity}CreateRequest` | `DepartmentCreateRequest` |
| 更新请求 | `{Entity}UpdateRequest` | `DepartmentUpdateRequest` |
| 响应 DTO | `{Entity}Dto` / `{Entity}SimpleDto` | `DepartmentDto`, `DepartmentSimpleDto` |

### 3.2 分层架构规范

| 层 | 职责 | 禁止事项 |
|---|------|---------|
| Controller | 参数接收与校验、权限控制、调用 Service、返回统一响应 | 禁止包含任何业务逻辑 |
| Service | 所有业务逻辑、数据验证、事务管理、分摊/费用计算 | 禁止直接操作 HttpContext |
| Model | 数据库实体映射、DTO 定义、枚举定义 | 禁止包含业务逻辑方法 |
| Common | 公共工具类（JWT、Excel、统一返回格式等） | 禁止引用 Service 或 Model |

### 3.4 Controller 规范

#### 3.4.1 基本结构

```csharp
/// <summary>
/// 实体管理控制器
/// </summary>
[ApiController]
[Route("api/[controller]")]
public class EntityController : ControllerBase
{
    private readonly IEntityService _entityService;
    private readonly ILogger<EntityController> _logger;

    public EntityController(
        IEntityService entityService,
        ILogger<EntityController> logger)
    {
        _entityService = entityService;
        _logger = logger;
    }

    /// <summary>
    /// 获取列表（分页）
    /// </summary>
    /// <param name="request">查询参数</param>
    /// <returns>分页结果</returns>
    [HttpGet]
    [Authorize]
    public async Task<ActionResult<ApiResult<PageResult<EntityDto>>>> GetList(
        [FromQuery] EntityQueryRequest request)
    {
        request.Normalize(); // 分页参数规范化
        var result = await _entityService.GetPagedListAsync(request);
        return Ok(ApiResult<PageResult<EntityDto>>.Success(result, "查询成功"));
    }

    /// <summary>
    /// 获取详情
    /// </summary>
    /// <param name="id">实体ID</param>
    /// <returns>实体详情</returns>
    [HttpGet("{id}")]
    [Authorize]
    public async Task<ActionResult<ApiResult<EntityDto>>> GetById(long id)
    {
        var result = await _entityService.GetByIdAsync(id);
        if (result == null)
        {
            return Ok(ApiResult<EntityDto>.Fail("不存在", 404));
        }
        return Ok(ApiResult<EntityDto>.Success(result));
    }

    /// <summary>
    /// 新增
    /// </summary>
    /// <param name="request">创建请求</param>
    /// <returns>创建的实体</returns>
    [HttpPost]
    [Authorize(Roles = "admin")]
    public async Task<ActionResult<ApiResult<EntityDto>>> Create(
        [FromBody] EntityCreateRequest request)
    {
        var result = await _entityService.CreateAsync(request);
        return Ok(ApiResult<EntityDto>.Success(result, "创建成功"));
    }

    /// <summary>
    /// 更新
    /// </summary>
    /// <param name="id">实体ID</param>
    /// <param name="request">更新请求</param>
    /// <returns>更新的实体</returns>
    [HttpPut("{id}")]
    [Authorize(Roles = "admin")]
    public async Task<ActionResult<ApiResult<EntityDto>>> Update(
        long id, [FromBody] EntityUpdateRequest request)
    {
        request.Id = id;
        var result = await _entityService.UpdateAsync(request);
        return Ok(ApiResult<EntityDto>.Success(result, "更新成功"));
    }

    /// <summary>
    /// 删除
    /// </summary>
    /// <param name="id">实体ID</param>
    /// <returns>删除结果</returns>
    [HttpDelete("{id}")]
    [Authorize(Roles = "admin")]
    public async Task<ActionResult<ApiResult<object>>> Delete(long id)
    {
        await _entityService.DeleteAsync(id);
        return Ok(ApiResult<object>.Success(null, "删除成功"));
    }
}
```

#### 3.4.2 规范要点

- 使用 `[ApiController]` 特性
- 路由模板使用 `[Route("api/[controller]")]`
- 所有需要认证的接口添加 `[Authorize]`
- 按角色控制使用 `[Authorize(Roles = "admin,finance")]`
- 查询参数使用 `[FromQuery]`，路径参数使用路由模板参数，请求体使用 `[FromBody]`
- 统一使用 `ApiResult<T>` 包装响应
- 方法必须使用 XML 文档注释 `/// <summary>`、`<param>`、`<returns>`
- 查询前调用 `request.Normalize()` 规范化分页参数

### 3.5 Service 层规范

#### 3.5.1 接口定义

```csharp
/// <summary>
/// 实体服务接口
/// </summary>
public interface IEntityService
{
    /// <summary>
    /// 获取分页列表
    /// </summary>
    Task<PageResult<EntityDto>> GetPagedListAsync(EntityQueryRequest request);

    /// 根据ID获取详情

    /// <summary>
    /// 创建
    /// </summary>
    /// <param name="request">创建请求</param>
    /// <returns>(成功, 消息, 实体ID)</returns>

    /// <summary>
    /// 更新
    /// </summary>
    /// <param name="request">更新请求</param>
    /// <returns>(成功, 消息)</returns>
    Task<(bool Success, string Message)> UpdateAsync(EntityUpdateRequest request);

    /// <summary>
    /// 删除
    /// </summary>
    /// <param name="id">实体ID</param>
    /// <returns>(成功, 消息)</returns>
    Task<(bool Success, string Message)> DeleteAsync(long id);

    /// <summary>
    /// 导入
    /// </summary>
    /// <param name="data">导入数据</param>
    /// <returns>(成功, 消息, 成功数, 失败数)</returns>
    Task<(bool Success, string Message, int SuccessCount, int FailCount)> ImportAsync(List<EntityCreateRequest> data);
```

#### 3.5.2 服务实现

```csharp
/// <summary>
/// 实体服务实现
/// </summary>
public class EntityService : IEntityService
{
    private readonly ISqlSugarClient _db;
    private readonly ILogger<EntityService> _logger;

    public EntityService(ISqlSugarClient db, ILogger<EntityService> logger)
    {
        _db = db;
        _logger = logger;
    }

    public async Task<PageResult<EntityDto>> GetPagedListAsync(EntityQueryRequest request)
    {
        var query = _db.Queryable<Entity>()
            .WhereIF(!string.IsNullOrEmpty(request.Keyword),
                e => e.Name.Contains(request.Keyword!))
            .WhereIF(request.IsEnabled.HasValue,
                e => e.IsEnabled == request.IsEnabled);

        var total = await query.CountAsync();

        var items = await query
            .OrderBy(e => e.SortOrder)
            .OrderBy(e => e.Id)
            .Skip((request.PageIndex - 1) * request.PageSize)
            .Take(request.PageSize)
            .Select<EntityDto>()
            .ToListAsync();

        return new PageResult<EntityDto>
        {
            Items = items,
            Total = total,
            PageIndex = request.PageIndex,
            PageSize = request.PageSize
        };
    }

    public async Task<(bool Success, string Message, long? Id)> CreateAsync(EntityCreateRequest request)
    {
        var exists = await _db.Queryable<Entity>()
            .Where(e => e.Code == request.Code)
            .FirstAsync();

        if (exists != null)
        {
            return (false, "编码已存在", null);
        }

        var entity = new Entity
        {
            Code = request.Code,
            Name = request.Name,
            SortOrder = request.SortOrder ?? 0,
            IsEnabled = true
        };

        await _db.Insertable(entity).ExecuteCommandAsync();

        _logger.LogInformation("创建实体: {Code} - {Name}", entity.Code, entity.Name);

        return (true, "创建成功", entity.Id);
    }

    public async Task<(bool Success, string Message)> UpdateAsync(EntityUpdateRequest request)
    {
        var entity = await _db.Queryable<Entity>()
            .Where(e => e.Id == request.Id)
            .FirstAsync();

        if (entity == null)
        {
            return (false, "不存在");
        }

        var exists = await _db.Queryable<Entity>()
            .Where(e => e.Code == request.Code && e.Id != request.Id)
            .FirstAsync();

        if (exists != null)
        {
            return (false, "编码已存在");
        }

        entity.Code = request.Code;
        entity.Name = request.Name;
        entity.SortOrder = request.SortOrder ?? 0;
        entity.Remark = request.Remark;
        entity.UpdatedAt = DateTime.Now;

        await _db.Updateable(entity).ExecuteCommandAsync();

        _logger.LogInformation("更新实体: {Id} - {Name}", entity.Id, entity.Name);

        return (true, "更新成功");
    }

    public async Task<(bool Success, string Message)> DeleteAsync(long id)
    {
        var entity = await _db.Queryable<Entity>()
            .Where(e => e.Id == id)
            .FirstAsync();

        if (entity == null)
        {
            return (false, "不存在");
        }

        var result = await _db.Deleteable<Entity>()
            .Where(e => e.Id == id)
            .ExecuteCommandAsync();

        if (result == 0)
        {
            return (false, "不存在");
        }

        _logger.LogInformation("删除实体: {Id}", id);

        return (true, "删除成功");
    }

    public async Task<(bool Success, string Message, int SuccessCount, int FailCount)> ImportAsync(
        List<EntityCreateRequest> data)
    {
        int successCount = 0;
        int failCount = 0;

        foreach (var item in data)
        {
            try
            {
                var (success, _, _) = await CreateAsync(item);
                if (success)
                {
                    successCount++;
                }
                else
                {
                    failCount++;
                }
            }
            catch
            {
                failCount++;
            }
        }

        return (true, $"导入完成，成功 {successCount} 条，失败 {failCount} 条", successCount, failCount);
    }
}
```

#### 3.5.3 规范要点

- 通过构造函数注入 `ISqlSugarClient` 和 `ILogger<T>`
- 使用 `WhereIF` 进行条件查询
- 事务使用 `UseTranAsync`
- 业务操作使用元组返回状态 `(bool Success, string Message, T? Data)`
- 使用结构化日志
- 创建/更新/删除操作返回元组而非直接抛异常

#### 3.6.3 请求 DTO

```csharp
/// <summary>
/// 分页查询请求基类
/// </summary>
public abstract class PageRequest
{
    /// <summary>
    /// 页码（从1开始）
    /// </summary>
    public int PageIndex { get; set; } = 1;

    /// <summary>
    /// 每页条数
    /// </summary>
    public int PageSize { get; set; } = 20;

    /// <summary>
    /// 规范化分页参数
    /// </summary>
    public virtual void Normalize()
    {
        if (PageIndex < 1) PageIndex = 1;
        if (PageSize < 1) PageSize = 20;
        if (PageSize > 100) PageSize = 100;
    }
}

/// <summary>
/// 查询参数
/// </summary>
public class EntityQueryRequest : PageRequest
{
    /// <summary>
    /// 搜索关键词
    /// </summary>
    public string? Keyword { get; set; }

    /// <summary>
    /// 是否启用
    /// </summary>
    public bool? IsEnabled { get; set; }
}

/// <summary>
/// 创建请求
/// </summary>
public class EntityCreateRequest
{
    [Required(ErrorMessage = "编码不能为空")]
    [MaxLength(20, ErrorMessage = "编码最长20个字符")]
    public string Code { get; set; } = string.Empty;

    [Required(ErrorMessage = "名称不能为空")]
    [MaxLength(100, ErrorMessage = "名称最长100个字符")]
    public string Name { get; set; } = string.Empty;

    public int? SortOrder { get; set; }

    [MaxLength(500)]
    public string? Remark { get; set; }
}

/// <summary>
/// 更新请求
/// </summary>
public class EntityUpdateRequest : EntityCreateRequest
{
    /// <summary>
    /// ID（由 Controller 设置）
    /// </summary>
    public long Id { get; set; }
}
```

### 3.7 统一响应格式

```csharp
/// <summary>
/// 统一 API 响应格式
/// </summary>
public class ApiResult<T>
{
    /// <summary>
    /// 状态码
    /// </summary>
    public int Code { get; set; }

    /// <summary>
    /// 消息
    /// </summary>
    public string Message { get; set; } = string.Empty;

    /// <summary>
    /// 数据
    /// </summary>
    public T? Data { get; set; }

    /// <summary>
    /// 时间戳
    /// </summary>
    public long Timestamp { get; set; } = DateTimeOffset.UtcNow.ToUnixTimeSeconds();

    /// <summary>
    /// 成功响应
    /// </summary>
    public static ApiResult<T> Success(T? data, string message = "操作成功")
    {
        return new ApiResult<T>
        {
            Code = 200,
            Message = message,
            Data = data
        };
    }

    /// <summary>
```

```csharp
    public void OnException(ExceptionContext context)
    {

        int code;
        string message;

            Message = message,
```

```csharp
/// <summary>
/// JWT 工具类
/// </summary>
public static class JwtHelper
{
    /// <summary>
    /// 生成 JWT Token
    /// </summary>
    public static string GenerateToken(long userId, string username, string roleCode,
        IConfiguration configuration)
    {
        var jwtSettings = configuration.GetSection("Jwt");
        var secretKey = jwtSettings["SecretKey"]!;
        var issuer = jwtSettings["Issuer"]!;
        var audience = jwtSettings["Audience"]!;
        var expirationMinutes = int.Parse(jwtSettings["ExpirationMinutes"]!);

        var claims = new[]
        {
            new Claim(ClaimTypes.NameIdentifier, userId.ToString()),
            new Claim(ClaimTypes.Name, username),
            new Claim(ClaimTypes.Role, roleCode),
            new Claim(JwtRegisteredClaimNames.Jti, Guid.NewGuid().ToString())
        };

        var key = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(secretKey));
        var credentials = new SigningCredentials(key, SecurityAlgorithms.HmacSha256);

        var token = new JwtSecurityToken(
            issuer: issuer,
            audience: audience,
            claims: claims,
            expires: DateTime.UtcNow.AddMinutes(expirationMinutes),
            signingCredentials: credentials
        );

        return new JwtSecurityTokenHandler().WriteToken(token);
    }
}
```

## 十、前后端字段映射规范

### 10.1 三层命名映射规则

系统涉及三层命名约定，必须严格遵循以下映射关系：

| 层级 | 命名风格 | 示例 |
|------|---------|------|
| 数据库字段 | `snake_case`（小写+下划线） | `room_name`, `building_id`, `created_at` |
| 后端 C# 属性 | `PascalCase`（大驼峰） | `RoomName`, `BuildingId`, `CreatedAt` |
| 前端 TypeScript 属性 | `camelCase`（小驼峰） | `roomName`, `buildingId`, `createdAt` |

**映射规则**：
- 数据库 → 后端：通过 SqlSugar 的 `[SugarColumn(ColumnName = "xxx")]` 特性映射
- 后端 → 前端：通过 ASP.NET Core JSON 序列化自动转换（PascalCase → camelCase）
- **前端字段名必须是后端字段名的 camelCase 形式，禁止自行重新命名**

### 10.2 映射示例

| 数据库字段 | 后端 C# 属性 | 前端 TS 属性 |
|-----------|-------------|-------------|
| `room_id` | `RoomId` | `roomId` |
| `room_name` | `RoomName` | `roomName` |
| `building_id` | `BuildingId` | `buildingId` |
| `floor_id` | `FloorId` | `floorId` |
| `qr_code_url` | `QrCodeUrl` | `qrCodeUrl` |
| `is_reservable` | `IsReservable` | `isReservable` |
| `created_at` | `CreatedAt` | `createdAt` |

### 10.3 C# 与 TypeScript 类型映射

| C# 类型 | TypeScript 类型 | 说明 |
|---------|----------------|------|
| `long` / `int` | `number` | 整数类型 |
| `byte` | `number` | 枚举/小整数 |
| `decimal` / `decimal?` | `number` / `number \| null` | 小数类型 |
| `bool` / `bool?` | `boolean` / `boolean \| null` | 布尔类型 |
| `string` / `string?` | `string` / `string \| undefined` | 字符串类型 |
| `DateTime` / `DateTime?` | `string` / `string \| undefined` | 日期时间（ISO 8601 字符串） |
| `List<T>` | `T[]` | 数组类型 |

### 10.4 强制规则

1. **前端禁止自行命名字段**：前端 TypeScript 接口属性名必须是后端 C# DTO 属性名的 camelCase 形式，禁止使用不同名称（如后端 `devices` 前端不能用 `facilities`）
2. **前端禁止自行命名分页参数**：分页参数统一使用 `pageIndex`/`pageSize`，禁止使用 `pageNum`/`page`/`currentPage` 等；分页响应的数据列表统一使用 `items`，禁止使用 `list`/`data`/`records` 等
3. **类型必须同步**：后端 DTO 字段变更时，必须同步更新前端 TypeScript 类型定义；新增字段需前后端同步添加
4. **Mock 数据必须一致**：Mock 数据的字段名和结构必须与真实 API 响应完全一致

### 10.5 代码审查检查项

- [ ] 前端字段名是否与后端 DTO 的 camelCase 映射一致
- [ ] 前端类型定义是否与后端 DTO 类型匹配
- [ ] 请求/响应参数名是否遵循映射规则，无自行改名
- [ ] 更新请求是否包含所有必要字段（如 `buildingId`、`floorId`）
- [ ] Mock 数据字段是否与 API 响应一致

## 十一、前后端路由对齐规范

### 11.1 前端 API 调用必须有对应后端路由（强制）

前端新增 API 调用时，必须验证对应后端路由已实现且可用，禁止出现「前端调了、后端没做」的 404。

**强制规则**：

1. **契约先行**：前后端接口契约先于双方实现落盘
2. **成对实现**：后端 Controller 的 CRUD 路由必须成对实现（如有 `POST /api/xxx/create`，配套 `GET /api/xxx/list` 不得遗漏）
3. **手动验证**：开发阶段应调一次 Swagger / curl 确认路由存在，构建检查不会捕获 404

### 11.2 代码审查检查项

- [ ] 前端新增 API 函数是否都有对应后端路由？
- [ ] 后端新增路由是否都更新了前端 API 层？
- [ ] 路由路径是否严格一致（`/api/tenant/packages` vs `/api/packages` 不能混用）？

> 来源：套餐升级页前端调 `GET /api/tenant/packages`，后端仅有 `POST upgrade` 无 GET action，运行时 404。
